# Skinnova

AI-powered acne detection and personalized skincare guidance system.

## Features

- Acne severity detection using TensorFlow CNN
- Supports image upload and camera capture
- Skin type selection
- Personalized skincare recommendations
- Ingredients to use
- Ingredients to avoid
- Morning and night skincare routine

## Technologies Used

- Python
- TensorFlow
- Streamlit
- NumPy
- Pillow

## Dataset

Acne Grading Classification Dataset (Kaggle)

## Run Locally

```bash
pip install streamlit tensorflow numpy pillow

python -m streamlit run app.py
